## 背景 / Background

智能问答是本项目的差异化能力。直接调用大模型容易产生幻觉，且答案无法溯源；采用 RAG 可让答案基于本地语料并给出出处。

## 需求描述 / Description

实现基于检索增强生成的智能问答，并展示答案的原文出处。

## 任务清单 / Tasks

- [ ] 实现检索环节：基于 #14 的全文检索获取与问题相关的原文片段作为证据
- [ ] 实现提示词组装：将问题与证据片段组装为结构化提示词，明确要求模型基于证据作答
- [ ] 实现 `POST /api/qa`：返回答案与证据引用列表（含章节定位）
- [ ] 实现前端问答页面：输入问题、展示答案、展示可点击的证据出处
- [ ] 实现降级：模型不可用时返回 503 并给出友好提示
- [ ] 补充集成测试（使用 mock 模型与真实检索）

## 验收标准 / Acceptance Criteria

- [ ] 提出一个能在原文中找到答案的问题，返回的答案内容能与原文证据一致
- [ ] 返回的证据列表中能包含章节定位信息，点击后能跳转到对应章节
- [ ] 当问题在原文中找不到相关证据时，能明确答复未找到依据，而非凭空编造答案
- [ ] 当输入为空或超长时，接口能返回 400 并给出明确提示
- [ ] 当大模型服务不可用时，接口能返回 503 且前端展示友好提示，不影响其余页面
- [ ] 集成测试中检索环节使用真实数据、模型环节使用 mock，全部通过
