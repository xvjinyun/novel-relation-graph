## 背景 / Background

前端需要作品列表、作品详情与章节内容接口来渲染页面，采集任务也需要通过接口触发。

## 需求描述 / Description

实现作品与章节相关的 REST 接口，并生成在线接口文档。

## 任务清单 / Tasks

- [ ] 实现 `POST /api/works`：创建采集任务，参数含 `title`、`source_url`，返回 `task_id`
- [ ] 实现 `GET /api/works`：作品列表，支持分页，返回 `items[]` 与 `total`
- [ ] 实现 `GET /api/works/{id}`：作品详情，含章节数与人物数统计
- [ ] 实现 `GET /api/works/{id}/chapters`：章节列表，支持分页
- [ ] 实现统一错误处理：400 参数错误、404 资源不存在、409 重复创建，返回结构化错误信息
- [ ] 实现参数校验：空标题、非法 URL 均返回 400
- [ ] 补充接口集成测试

## 验收标准 / Acceptance Criteria

- [ ] 调用 `POST /api/works` 并传入合法参数，能返回 `task_id` 且任务进入队列
- [ ] 当 `title` 为空时，接口能返回 400 并给出明确错误字段说明
- [ ] 当 `source_url` 格式非法时，接口能返回 400 而非抛出未捕获异常
- [ ] 当重复创建同一来源 URL 的作品时，接口能返回 409 而非产生重复数据
- [ ] 当查询不存在的 `work_id` 时，接口能返回 404 且不返回空数据结构伪装成功
- [ ] 接口文档能在 `/docs` 路径自动生成并可在线调试
- [ ] 集成测试覆盖正常、边界、异常三类场景并全部通过
