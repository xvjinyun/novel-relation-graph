## 背景 / Background

章节摘要与人物小传是考核方案鼓励的 AI 生成式能力，能显著提升作品的可用性，也是本组沉淀 AI 辅助开发经验的主要载体。

## 需求描述 / Description

接入大模型 API，实现章节摘要与人物小传的自动生成。

## 任务清单 / Tasks

- [ ] 封装大模型客户端，支持通过环境变量配置 `LLM_API_BASE`、`LLM_API_KEY`、`LLM_MODEL`
- [ ] 实现章节摘要生成：按章调用，结果入库并缓存，避免重复计费
- [ ] 实现人物小传生成：汇总人物出场章节与关系作为上下文，生成人物简介
- [ ] 实现调用限流与失败重试，避免超额调用
- [ ] 实现降级：模型不可用时返回友好提示，不影响其余功能
- [ ] 将 AI 辅助开发的提示词设计、校验方法与踩坑经验整理为 `docs/ai-dev-experience.md`
- [ ] 补充单元测试（使用 mock，不产生真实调用）

## 验收标准 / Acceptance Criteria

- [ ] 对测试章节调用摘要接口，能返回长度适中且内容相关的摘要文本
- [ ] 对同一章节重复调用两次，第二次能命中缓存且不产生新的 API 调用
- [ ] 当 API Key 未配置时，能返回明确的配置缺失提示，而非抛出未捕获异常
- [ ] 当大模型接口超时或返回错误时，能自动重试至多 3 次后降级返回友好提示
- [ ] 当模型不可用时，作品的其余页面能正常访问，不受影响
- [ ] 测试全程使用 mock，不产生真实 API 费用
- [ ] `docs/ai-dev-experience.md` 已入库，记录提示词设计与校验方法
