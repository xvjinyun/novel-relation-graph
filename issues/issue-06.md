## 背景 / Background

人物实体识别、情感计算、关系抽取全部依赖高质量的分词与词性标注结果。古典白话文的用词习惯与现代汉语不同，需要评估并选定合适的分词工具。

## 需求描述 / Description

接入中文分词与词性标注能力，封装为统一服务接口，供后续分析模块调用。

## 任务清单 / Tasks

- [ ] 对比评估 HanLP 与 jieba 在古典白话文样本上的分词效果，将结论写入 `docs/adr/` 作为 ADR-006
- [ ] 实现 `Tokenizer` 服务封装，统一暴露 `cut(text)` 与 `pos_tag(text)` 两个方法
- [ ] 实现分词结果缓存（按段落哈希缓存，避免重复计算）
- [ ] 实现批量处理接口，支持一次处理整章文本
- [ ] 补充单元测试与性能基准测试

## 验收标准 / Acceptance Criteria

- [ ] 给定一段古典白话文样句，分词结果中人名能被完整切出而未被拆散
- [ ] `pos_tag` 能返回每个词对应的词性标记，人名标记为 `nr`
- [ ] 对同一段文本重复调用两次，第二次能命中缓存且返回结果与首次一致
- [ ] 对单章（约 5000 字）文本的分词处理，能在本机 5 秒内完成
- [ ] 当输入为空字符串时，能返回空列表而非抛出异常
- [ ] 单元测试覆盖率不低于 60%
