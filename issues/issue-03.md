## 背景 / Background

项目需要从多个开放授权的公版文本站点采集作品，不同站点的目录页与章节页结构各不相同，需要一个支持多来源适配的采集框架。

## 需求描述 / Description

实现基于 Scrapy 的采集器主框架，支持通过配置新增站点来源，而无需修改核心代码。

## 任务清单 / Tasks

- [ ] 定义 `SiteAdapter` 抽象基类，约定 `list_works()` 与 `fetch_chapter()` 两个接口方法
- [ ] 实现首个站点适配器（开放授权公版文本站点），从配置读取站点地址与选择器
- [ ] 实现采集任务编排：作品目录页 → 章节列表 → 逐章正文，逐层入库
- [ ] 接入 #1 的 robots 校验与限速器，接入 #2 的抽取清洗管道
- [ ] 实现采集任务的进度上报与失败重试（最多 3 次，指数退避）
- [ ] 补充集成测试（使用本地 HTML 夹具，不发起真实网络请求）

## 验收标准 / Acceptance Criteria

- [ ] 给定站点配置，能成功列出该站点的作品目录并解析出作品标题与详情页地址
- [ ] 对单部作品，能按章节顺序采集全部章节并按序号入库，章节序号连续无跳号
- [ ] 当某个章节请求失败时，能自动重试至多 3 次；3 次仍失败则记录错误并继续后续章节，不中断整部作品的采集
- [ ] 当站点地址不可达时，能记录错误日志并以非零状态结束任务，而非无限等待
- [ ] 新增一个站点来源时，能通过新增配置与适配器类完成，不修改采集框架核心代码
- [ ] 集成测试全程不发起真实网络请求，使用本地 HTML 夹具
