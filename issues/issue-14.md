## 背景 / Background

智能问答的检索增强环节与用户的原文查找需求，都依赖高效的全文检索能力。MySQL 的 LIKE 查询在长文本上性能不足。

## 需求描述 / Description

接入 Elasticsearch 实现章节正文的全文检索。

## 任务清单 / Tasks

- [ ] 搭建 Elasticsearch 容器并配置中文分词器（IK 或 smartcn）
- [ ] 实现章节入库时的索引同步：新增与更新章节均同步到 ES
- [ ] 实现 `POST /api/search`：支持关键字检索，返回命中章节片段与高亮
- [ ] 实现检索结果的分页与相关度排序
- [ ] 实现 ES 不可用时的降级：回退到 MySQL LIKE 查询并标记降级状态
- [ ] 补充集成测试

## 验收标准 / Acceptance Criteria

- [ ] 索引一部含 3 章的测试作品后，能检索到其中存在的关键词并定位到正确章节
- [ ] 检索结果中能包含关键词高亮片段，可直接用于前端展示
- [ ] 当检索关键字为空时，接口能返回 400 而非返回全量数据
- [ ] 当检索无结果时，能返回空列表且不报错
- [ ] 当 ES 服务不可用时，接口能降级返回 MySQL 查询结果，并在响应中标记降级
- [ ] 当章节内容更新后，索引能同步更新，检索到的是最新内容
