## 背景 / Background

情感曲线是本项目区别于普通人物关系图谱的特色功能，能直观呈现全书叙事节奏，也是前端可视化的重要数据来源。

## 需求描述 / Description

实现章节粒度的情感值计算，输出全书情感序列。

## 任务清单 / Tasks

- [ ] 选定情感词典方案（如大连理工大学情感词典或基于预训练模型打分），评估后写入 ADR-007
- [ ] 实现 `SentimentAnalyzer`：对每章正文计算情感得分，归一化到 `[-1, 1]` 区间
- [ ] 实现批量计算与入库，写入 `sentiment` 表
- [ ] 实现异常章节标记：情感值为 0 或绝对值异常高的章节标记待核查
- [ ] 补充单元测试，覆盖正面、负面、中性三类样本

## 验收标准 / Acceptance Criteria

- [ ] 对一段明显正面的测试文本，能计算出大于 0 的情感得分
- [ ] 对一段明显负面的测试文本，能计算出小于 0 的情感得分
- [ ] 对一段中性叙述文本，情感得分能落在 `[-0.2, 0.2]` 区间内
- [ ] 情感得分能全部落在 `[-1, 1]` 区间内，不出现越界值
- [ ] 当章节正文为空时，能标记该章节待核查而非赋予默认值 0 并静默通过
- [ ] 对一部 100 回的作品，全量情感计算能在 10 分钟内完成
