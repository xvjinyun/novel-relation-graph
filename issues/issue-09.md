## 背景 / Background

人物关系是本项目最核心的分析产出。需要基于人物在同一上下文窗口内的共现情况，计算关系强度并生成带权重的边。

## 需求描述 / Description

实现基于滑动窗口的人物共现抽取算法，生成人物关系图数据。

## 任务清单 / Tasks

- [ ] 实现滑动窗口共现统计：窗口大小可配置（默认一个段落），统计窗口内人物两两共现次数
- [ ] 实现关系权重计算：以全书共现总次数作为权重，并输出归一化权重
- [ ] 实现关系数据的批量入库，写入 `relation` 表
- [ ] 实现算法的边界处理：单章无共现、单人物独占窗口等情况
- [ ] 实现抽取结果的可视化验证脚本，输出前 N 条强关系供人工抽查
- [ ] 补充单元测试，覆盖正常共现、无共现、窗口边界三类场景

## 验收标准 / Acceptance Criteria

- [ ] 对一段已知两人共现 3 次的测试文本，能计算出这两人之间权重为 3
- [ ] 当窗口内只有一个人物的多种称谓时，能在归一后视为同一人，不产生自环边
- [ ] 当某章不存在任何共现时，能正常返回空关系列表而不报错
- [ ] 当窗口大小设为整章时，权重结果能与设为段落时的结果区分开，且配置生效
- [ ] 对一部 100 回的作品，全量关系抽取能在 10 分钟内完成
- [ ] 单元测试覆盖三类场景并全部通过
