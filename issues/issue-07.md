## 背景 / Background

人物是本项目分析的核心对象。需要自动从章节正文识别出人名实体，并统计每个人物在各章节的出场频次，作为图谱节点权重与人物详情页的数据来源。

## 需求描述 / Description

实现基于词性标注的人名实体识别，并统计人物在各章节的出现频次。

## 任务清单 / Tasks

- [ ] 实现 `CharacterExtractor`：基于 `nr` 词性标记提取人名候选，过滤单字人名与常见误判
- [ ] 实现频次统计：输出 `Character(name, chapter_no, count)` 明细与全书总频次
- [ ] 实现停用词与虚词过滤，剔除「某」「此人」等非具体人物指代
- [ ] 实现识别结果的置信度标记，低置信结果单独标记以便人工校对
- [ ] 补充单元测试，覆盖含多人名、含无人名、含误判样本三类

## 验收标准 / Acceptance Criteria

- [ ] 对含已知人物表的一段测试文本，能识别出其中全部人名，召回率不低于 80%
- [ ] 识别结果中能不包含单字人名与「某人」「此人」等泛指词
- [ ] 对单个人物，能正确统计其在每一章的出现次数，各章之和等于全书总频次
- [ ] 当章节正文不含任何人名时，能返回空列表且不产生数据库写入
- [ ] 当同一人物在同一章出现 3 次时，该章计数能为 3
- [ ] 单元测试覆盖三类样本并全部通过
