## 背景 / Background

用户点击图谱节点后需要查看人物详情，包括全书出场分布与主要关系，这是理解人物重要性的关键视图。

## 需求描述 / Description

实现人物详情页面，展示出场曲线与关系列表。

## 任务清单 / Tasks

- [ ] 实现人物详情页路由与布局
- [ ] 使用 ECharts 实现出场频次折线图：横轴为章节序号，纵轴为该章出现次数
- [ ] 实现主要关系列表：按权重降序展示相关人物，可点击跳转
- [ ] 实现原文片段展示：列出该人物出现的代表性章节片段
- [ ] 实现加载态与空数据处理
- [ ] 补充前端组件测试

## 验收标准 / Acceptance Criteria

- [ ] 打开人物详情页后，能正确展示该人物名称、总频次与主要关系列表
- [ ] 出场曲线图的横轴章节数能与该作品实际章节总数一致
- [ ] 点击曲线上某一章的数据点，能跳转到该章节正文
- [ ] 当人物无任何关系时，能展示空状态提示而非报错
- [ ] 当接口返回 404 时，页面能展示资源不存在提示而非白屏
- [ ] 关系列表能按权重降序排列，与后端返回顺序一致
