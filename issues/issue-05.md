## 背景 / Background

中文古典小说以章回体组织（如「第一回 甄士隐梦幻识通灵」），现代标点版本亦有「第一章」等格式。若不能正确切分章节，情感曲线与人物出场统计都将失去章节维度。

## 需求描述 / Description

实现章回标题的正则识别与章节切分，支持常见章回体与现代章节编号两种格式。

## 任务清单 / Tasks

- [ ] 归纳并实现章回标题正则规则：中文数字章回（`第[一二三四五六七八九十百千]+回`）、阿拉伯数字章节（`第\d+章`）、纯数字编号
- [ ] 实现章节切分器：按标题位置将全文切分为有序章节列表，输出 `(chapter_no, title, content)`
- [ ] 实现切分结果的完整性校验：章节序号连续、无章节内容为空
- [ ] 针对识别失败的样本提供人工修正入口（标题规则可在配置文件中扩展）
- [ ] 补充单元测试，覆盖三种标题格式与无标题的边界样本

## 验收标准 / Acceptance Criteria

- [ ] 对含第 1 回至第 120 回的标准章回体文本，能切分出 120 个章节且序号连续无跳号
- [ ] 对使用「第一章」格式的现代标点本，能正确识别并切分
- [ ] 当文本中不含任何章节标题时，能将全文作为单一章节处理，而非切分失败
- [ ] 当出现重复标题或序号错乱时，能记录告警日志并按实际顺序编号
- [ ] 当章节内容为空时，能标记该章节并计入统计，不导致整体切分失败
- [ ] 单元测试覆盖上述场景并全部通过
