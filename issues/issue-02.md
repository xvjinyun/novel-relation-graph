## 背景 / Background

采集到的原始 HTML 包含导航栏、广告、脚本、页脚等噪音，直接入库会污染后续的分词与实体识别结果，导致人物识别准确率下降。

## 需求描述 / Description

实现一套可配置的正文抽取与清洗管道，将原始 HTML 转换为结构化、干净的章节正文。

## 任务清单 / Tasks

- [ ] 实现基于 BeautifulSoup 的正文区域定位策略（支持按 CSS 选择器配置，默认值存放于配置文件）
- [ ] 实现噪音移除：清除 `script`、`style`、`nav`、`footer`、`aside` 标签及其内容
- [ ] 实现文本规范化：全角半角统一、连续空白折叠、不可见字符剔除
- [ ] 实现抽取结果的质量校验（正文长度阈值、章节标题非空），不达标则标记失败并告警
- [ ] 补充单元测试，覆盖含广告、含脚本、正文为空三类样本

## 验收标准 / Acceptance Criteria

- [ ] 给定一段含导航栏与广告的 HTML 样本，能正确抽取正文且不残留导航链接文字
- [ ] 当抽取后正文长度低于配置阈值（默认 50 字）时，能判定为失败并在日志中记录该 URL
- [ ] 当输入 HTML 格式异常（标签未闭合）时，能正常完成抽取而不抛出异常
- [ ] 当输入为空字符串时，能返回空结果并标记失败，而非崩溃
- [ ] 清洗后文本中能不再包含连续多个空格与制表符
- [ ] 单元测试覆盖率不低于 60%
