## 背景 / Background

情感曲线是呈现全书叙事节奏的特色视图，需要与 #10 的情感计算能力对接并在前端展示。

## 需求描述 / Description

使用 ECharts 实现情感曲线可视化页面。

## 任务清单 / Tasks

- [ ] 实现情感曲线页面：横轴为章节序号，纵轴为情感得分
- [ ] 实现正负情感区间配色，零轴参考线标注
- [ ] 实现点击数据点跳转至对应章节正文
- [ ] 实现与作品详情页的入口联动
- [ ] 实现加载态、空数据与接口错误态处理
- [ ] 补充前端组件测试

## 验收标准 / Acceptance Criteria

- [ ] 打开情感曲线页面后，能正确渲染全部章节的情感得分折线
- [ ] 折线图横轴章节数能与该作品实际章节总数一致
- [ ] 点击某一章的数据点，能跳转到该章节正文
- [ ] 当作品尚未完成情感计算时，能展示处理中状态而非报错
- [ ] 当接口返回错误时，页面能展示错误提示且不白屏
- [ ] 零轴参考线能正确显示，正负区间配色区分明显
