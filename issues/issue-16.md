## 背景 / Background

人物关系图谱是本项目的核心展示功能，也是答辩演示的主要看板。当前前端尚无图谱渲染能力。

## 需求描述 / Description

使用 AntV G6 实现人物关系图谱的可视化页面。

## 任务清单 / Tasks

- [ ] 搭建 Vue 3 + Element Plus 前端工程骨架，配置路由与布局
- [ ] 实现作品列表页，展示已收录作品与统计信息
- [ ] 实现图谱页面：使用 AntV G6 力导向布局渲染节点与边，节点大小按人物频次映射
- [ ] 实现交互：缩放、拖拽、点击节点查看人物详情、按权重过滤弱关系
- [ ] 实现加载态与错误态处理，接口异常时展示提示而非白屏
- [ ] 补充前端组件测试

## 验收标准 / Acceptance Criteria

- [ ] 打开图谱页面后，能在 3 秒内完成 100 节点规模的首屏渲染
- [ ] 点击某个节点后，能展示该人物的名称与总频次信息
- [ ] 拖动权重过滤滑块后，能隐藏低于阈值的边，且页面不闪烁、不重复请求接口
- [ ] 当后端接口返回错误时，页面能展示错误提示且保持可用，不出现白屏
- [ ] 当作品尚无关系数据时，页面能展示空状态引导而非报错
- [ ] 页面缩放与拖拽操作流畅，节点不出现重叠不可读的情况
