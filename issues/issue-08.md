## 背景 / Background

中文小说中同一人物有大量不同称谓：「林黛玉」「颦儿」「林姑娘」「黛玉」实为一人。若不归并，图谱会出现多个重复节点，人物关系与实际严重不符。

## 需求描述 / Description

实现别名词典与归一处理，将同一人物的不同称谓合并为同一实体，并提供人工校对入口。

## 任务清单 / Tasks

- [ ] 设计并实现 `alias` 别名词典表结构（主名、别名列表、来源、是否人工确认）
- [ ] 实现自动别名挖掘：基于姓氏与名字子串规则生成候选（如「黛玉」→「林黛玉」）
- [ ] 实现归一处理：将识别出的所有人名映射到主名，输出归并后的人物集合
- [ ] 实现人工校对接口与前端入口，支持合并、拆分、删除别名映射
- [ ] 实现别名词典的导入导出（JSON 格式）
- [ ] 补充单元测试，覆盖自动归并、人工覆盖、冲突检测三类场景

## 验收标准 / Acceptance Criteria

- [ ] 对含「林黛玉」「颦儿」「林姑娘」的测试文本，能将三者归并为同一人物，图谱中该人物只有一个节点
- [ ] 当自动挖掘产生的候选别名有误时，能通过人工校对接口覆盖，且人工结果优先级高于自动结果
- [ ] 当两个不同人物的别名发生冲突时，能检测并标记冲突，交由人工处理而非自动合并
- [ ] 归并能正确累加频次：归并后该人物的总频次等于各称谓频次之和
- [ ] 别名词典能以 JSON 格式完整导出并重新导入，导入后结果与导出前一致
- [ ] 单元测试覆盖三类场景并全部通过
